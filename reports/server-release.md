# Проверка комплекта серверной версии — 13.09.2026

## Выполнено

- 17 автоматических тестов Python: расчёт рабочих дней и границы 17:00:00, решение +4/+7 без влияния времени, архив только завершённых, 50 пользователей с одинаковыми ФИО, обязательные поля и роли, время возврата до секунд, экспорт до 45 дней, импорт 9999 строк, обязательная сессия, Origin/CSRF, bcrypt, первая смена пароля, отсутствие доступа к демонстрационному коду.
- 14 регрессионных проверок демонстрационной логики на 50 пользователях и 10 000 заявок. Привязка к ID исправляет доступ тёзок и сохраняет назначения при изменении ФИО. Результат: `scale-50-users-regression.json`. Старый отчёт сохранён как история предыдущей версии.
- Синтаксическая проверка Python, JavaScript, первоначальной PostgreSQL-схемы (18 SQL-команд) и YAML-конфигурации семи Docker-сервисов.
- В браузере проверены реальная страница входа и интерфейс дашборда/таблицы/поиска ФИО на отдельном read-only тестовом API с 50 пользователями. Поиск с другим регистром и пробелами нашёл обе записи тёзок. Эта UI-проверка не использовала PostgreSQL.

## Требуется на целевом сервере

Docker и PostgreSQL недоступны в текущем окружении. Поэтому не выполнены: сборка контейнера, применение схемы в настоящей PostgreSQL, полный сценарий API с постоянным сохранением, HTTPS/DNS, проверка восстановления резервной копии, импорт/выгрузка через сервер под нагрузкой. До выполнения этих пунктов комплект не считается принятым в промышленную эксплуатацию.

Для 50 параллельных сессий приложен `scripts/load_test.py`. Он использует 50 заранее созданных тестовых учётных записей всех шести ролей с уже сменёнными временными паролями и выполняет 750 запросов чтения. Файл учётных данных хранится только локально на тестовом сервере, не добавляется в Git и удаляется после проверки.

```sh
python scripts/load_test.py --url https://TEST_DOMAIN --accounts /private/test-accounts.json
```

Результат сохраняется без логинов и паролей в `reports/server-load.json`. Критерий скрипта: все запросы успешны, представлены шесть ролей, максимальное время API-ответа до 2 секунд. Импорт 9999 строк до 60 секунд и выгрузка до 30 секунд проверяются отдельно. Требование отклика интерфейса включает браузер и сеть, поэтому один API-тест его полностью не подтверждает.

Инструкция запуска и приёмки: `deploy/README.md`.
